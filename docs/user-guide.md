# Инструкция по работе с админкой

**Адрес:** https://admin.snzbeachvolleyball25.ru

---

## Вход в систему

Откройте сайт в браузере, введите логин и пароль.
Сессия действует 24 часа — после этого нужно войти снова.

---

## Роли

В системе две роли:

| Роль | Возможности |
|------|------------|
| **Редактор** | Создавать и редактировать черновики статей и врачей |
| **Администратор** | Всё то же самое + публикация, управление пользователями, настройки |

---

## Структура контента

```
Животное (например: Кошка 🐱)
  └── Категория (например: Отравление ☠️)
       └── Статья (например: Что делать при отравлении)

Врач (ФИО, фото, специализация)
  └── Расписание (дни недели + время)
```

---

## Животные

Раздел **«Животные»** в левом меню.

### Добавить животное
1. Нажмите **«Добавить»**
2. Введите название, slug, иконку-эмодзи, порядок сортировки
3. Нажмите **«Сохранить»**

---

## Категории

Раздел **«Категории»** — сгруппированы по животным, нажмите на животное чтобы раскрыть.

---

## Статьи

Раздел **«Статьи»** в левом меню.

### Добавить статью
1. Нажмите **«Добавить»**
2. Введите **заголовок** — slug заполнится автоматически
3. Напишите текст в редакторе
4. Отметьте нужные **категории**
5. Нажмите **«Сохранить»**

### Статусы статей
- **Черновик** — видна только в админке, в боте не отображается
- **Опубликована** — видна пользователям в боте

Кнопка публикации (иконка 📤) доступна только администратору.

### Редактор текста

| Кнопка | Действие |
|--------|----------|
| H1 / H2 / H3 | Заголовки |
| **Ж** | Жирный |
| *К* | Курсив |
| • список | Маркированный список |
| 1. список | Нумерованный список |

**Советы:**
- Используйте H2 для разделов — хорошо выглядит в Telegram
- Нумерованный список — для пошаговых инструкций
- Маркированный — для симптомов и признаков
- Пишите кратко: владелец животного в стрессе

## Врачи

Раздел **«Врачи»** в левом меню.

### Добавить врача
1. Нажмите **«Добавить»**
2. Заполните **ФИО** (обязательно), специализацию, описание, контакты
3. Нажмите **«Сохранить»**
4. После сохранения загрузите **фото** (JPG/PNG/WebP, до 5 МБ)

### Статусы врачей
- **Черновик** — не виден в боте
- **Опубликован** — виден пользователям вместе с расписанием

Публикацию выполняет только администратор.

---

## Расписание

Раздел **«Расписание»** — общий вид расписания клиники на выбранный период.

### Как заполнить расписание врача
1. Откройте карточку врача (раздел «Врачи» → ✏️)
2. В блоке **«Еженедельное расписание»** выберите день, время начала и конца, нажмите **«Добавить»**
3. Повторите для каждого рабочего дня

### Исключения
В блоке **«Исключения»** можно задать на конкретную дату:
- **Выходной** — врач не работает в этот день даже если он рабочий
- **Другое время** — изменённый график на конкретную дату

### Период отображения
Администратор может выбрать сколько вперёд показывать расписание в боте: 1 / 2 / 3 / 4 недели или месяц. Настройка в правом верхнем углу раздела «Расписание».

## Пользователи

Раздел **«Пользователи»** — только для администратора.

### Добавить пользователя
1. Нажмите **«Добавить»**
2. Введите логин, пароль (минимум 6 символов), выберите роль
3. Нажмите **«Создать»**

Удалить можно любого пользователя кроме себя.

---

## Частые вопросы

**Как статья попадает в бот?**
Только после публикации — нажмите кнопку 📤 (только для администратора).

**Как врач появляется в боте?**
После публикации карточки. Расписание отображается если оно заполнено.

**Если ушёл со страницы не сохранив — данные потеряются?**
Система предупредит перед уходом — появится диалог подтверждения.

**Забыл пароль?**
Обратитесь к администратору — он создаст новый аккаунт или попросит разработчика сбросить пароль.

**Что такое slug?**
Техническое название на латинице, используется в адресе. Менять slug существующих записей не рекомендуется.
