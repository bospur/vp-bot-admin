# Инструкция по работе с админкой

**Адрес:** https://admin.snzbeachvolleyball25.ru

---

## Вход в систему

Откройте сайт в браузере, введите логин и пароль, которые вам выдал разработчик.
Сессия действует 24 часа — после этого нужно войти снова.

---

## Структура контента

Контент организован в три уровня:

```
Животное (например: Кошка 🐱)
  └── Категория (например: Отравление ☠️)
       └── Статья (например: Что делать при отравлении)
```

Пользователь в Telegram-боте выбирает животное → категорию → читает статью.

---

## Животные

Раздел **«Животные»** в левом меню.

### Добавить животное
1. Нажмите **«Добавить»** (или ➕ на телефоне)
2. Введите название (например: *Кошка*)
3. Введите slug — краткое английское обозначение (например: *cat*)
4. Выберите иконку-эмодзи — нажмите на поле и выберите из списка
5. Укажите порядок сортировки (0 — первый в списке)
6. Нажмите **«Сохранить»**

### Редактировать / Удалить
Нажмите иконку ✏️ или 🗑️ напротив животного.

> ⚠️ При удалении животного все его категории и связанные статьи останутся в базе, но потеряют привязку.

---

## Категории

Раздел **«Категории»** в левом меню.

Категории сгруппированы по животным — нажмите на животное чтобы раскрыть список.

### Добавить категорию
1. Нажмите **«Добавить»**
2. Выберите животное из выпадающего списка
3. Введите название (например: *Отравление*)
4. Введите slug (например: *otravlenie*)
5. Выберите иконку-эмодзи
6. Укажите порядок сортировки
7. Нажмите **«Сохранить»**

---

## Статьи

Раздел **«Статьи»** в левом меню.

### Добавить статью
1. Нажмите **«Добавить»**
2. Введите **заголовок** — slug заполнится автоматически
3. При необходимости отредактируйте **slug** вручную (только латинские буквы и дефис)
4. В поле **«Содержание»** напишите текст статьи с помощью редактора
5. В разделе **«Категории»** отметьте галочками нужные категории (можно несколько)
6. Нажмите **«Сохранить»**

### Редактор текста

Панель инструментов редактора:

| Кнопка | Действие |
|--------|----------|
| **H1** | Большой заголовок |
| **H2** | Заголовок второго уровня |
| **H3** | Заголовок третьего уровня |
| **Ж** | Жирный текст |
| **К** | Курсив |
| • список | Маркированный список |
| 1. список | Нумерованный список |

**Советы по написанию статей:**
- Начните с заголовка H2 — он хорошо отображается в Telegram
- Используйте нумерованный список для пошаговых инструкций
- Используйте маркированный список для признаков/симптомов
- Пишите кратко и понятно — владелец животного в стрессе

**Пример хорошей структуры:**
```
## Признаки отравления
• Рвота
• Вялость
• Отказ от еды

## Первая помощь
1. Уберите источник отравления
2. Не давайте еду и воду 2 часа
3. Позвоните в клинику

## Когда срочно к врачу
• Судороги
• Потеря сознания
```

### Привязка к категориям
Одна статья может относиться к нескольким категориям. Это удобно если, например, статья о рвоте подходит и к разделу «Отравление» и к разделу «Желудок».

## Частые вопросы

**Как статья попадает в бот?**
Сразу после сохранения — обновление мгновенное.

**Можно ли удалить статью которую видят пользователи?**
Да, удаление немедленное. Если статья нужна — лучше отвязать её от категорий вместо удаления.

**Забыл пароль — что делать?**
Обратитесь к разработчику.

**Что такое slug?**
Это техническое название на латинице, используется в адресе. Например статья «Отравление кошки» может иметь slug `otravlenie-koshki`. Менять slug у существующих статей не рекомендуется.
